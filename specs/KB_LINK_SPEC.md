# 知识库 Wikilink 语法规范

> 版本：v1.0 | 最后更新：2026-06-04

## 概述

本规范定义 `.ai/kb/` 知识库中使用的 `[[wiki-link]]` 语法，与 Obsidian 兼容，用于在知识条目之间建立可遍历的双向链接网络。

## 语法

### 基本链接

```
[[条目名]]
```

- `条目名` 必须与 `kb/index.md` 中注册的条目标题**完全一致**（大小写敏感）
- 链接可出现在知识库条目的任何位置——正文、代码块注释、表格均有效
- 链接解析时忽略 `条目名` 前后的空白字符

### 锚点链接

```
[[条目名#章节名]]
```

- `#章节名` 指向目标条目内的特定 `##` 章节标题（不含 `[+]` 状态标记）
- 章节名为可选部分，缺失时默认为条目全文
- 锚点匹配规则：去掉章节名首尾空白后，与目标条目 `## [+] 标题` 中的 `标题` 部分做精确匹配

### 无效链接

以下情况视为无效链接，解析时跳过并可选地发出警告：

- 目标条目不在此 `kb/index.md` 注册表中
- `条目名` 为空字符串（`[[]]`）
- 锚点所指定的章节在目标条目中不存在

## 链接方向

链接图是**有向图**：

- **正向引用**：条目 A 正文中包含 `[[B]]`，建立边 A → B
- **反向引用**（Backlink）：从 B 的视角，A 引用了 B

反向引用在构建图谱时自动推导，无需显式声明。

## 转义

当需要在正文中显示 `[[` 字面量而不触发链接时，使用反斜杠转义：

```
\[[不是链接]]
```

转义反斜杠不会被渲染，客户端展示时应去除。

## 链接图构建规则

1. 解析所有 `.ai/kb/*.md` 文件（排除 `index.md`）
2. 从 `kb/index.md` 读取注册表，建立 `标题名 → {file, category}` 映射
3. 对每个文件中的 `[+]` 条目，提取内容中所有 `[[...]]` 链接
4. 条目内部的自引用（条目 A 中引用 `[[A]]`）忽略，不生成边
5. 同一文件内的多个同向边去重（仅保留一条）

## 与 Obsidian 的兼容性

| 特性 | 本项目 | Obsidian |
|------|--------|----------|
| `[[条目名]]` | ✅ | ✅ |
| `[[条目名#章节]]` | ✅ | ✅ |
| `[[条目名\|别名]]` | ❌（忽略显示名，仅取条目名） | ✅ |
| `![[嵌入]]` | ❌ | ✅ |
| 反向链接面板 | 通过 `graph.json` 查询 | 内置 |

## 示例

```markdown
## [+] OAuth2 登录流程 (2026-05-20)

采用 Authorization Code Grant 流程，详见 [[状态机模式约定]] 中的状态定义。

客户端注册依赖于 [[环境搭建#前置依赖安装]] 中描述的依赖项。
```

解析结果：
- 正向边：`OAuth2 登录流程` → `状态机模式约定`，`OAuth2 登录流程` → `环境搭建`
- 反向边：`状态机模式约定` 被 `OAuth2 登录流程` 引用
