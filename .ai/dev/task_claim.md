# 任务归属规范

> 多人/多 Agent 协作时，Agent 在接手任务前必须声明模块归属，避免任务重复或遗漏。

## 声明格式

在 `.ai/dev/current.md` 中使用以下格式声明任务：

```markdown
@{username} [模块] {状态}：{任务描述}
```

## 字段说明

| 字段 | 格式 | 说明 |
|------|------|------|
| `@{username}` | `@` + Git 用户名 | 任务归属者，不可为空 |
| `[模块]` | `[模块名]` | 正在修改的模块名，无则填 `[-]` |
| `{状态}` | `进行中` / `阻塞` / `已完成` | 任务当前状态 |
| `{任务描述}` | 自由文本 | 一句话描述当前工作和进度 |

## 状态流转

```
进行中 ──→ 阻塞 ──→ 进行中
   │                    │
   └──→ 已完成 ←────────┘
```

## 文件锁定

当修改涉及共享文件时，在声明行下追加锁定行：

```markdown
@{username} [模块] 进行中：修改 xxx 功能
  🔒 file_a.py, file_b.py
```

**约束**：
- Agent 修改任何文件前，必须检查 `current.md` 中是否有其他 Agent 的 🔒 锁定
- 若文件已被锁定，须等待锁定者完成或与锁定者协调
- 同一用户可锁定多个文件，同一文件不可被多人同时锁定
- 任务完成/阻塞时须移除锁定

## 示例

```markdown
# 当前进度

**总体状态**：阶段二开发中

@Liuary [rule_engine] 进行中：实现 sync_status Skill
  🔒 lib/rule_engine.py

@huayinghuo [适配器] 阻塞：等待 Claude Code API 权限

@guest [文档] 已完成：补充 README 安装说明
```
