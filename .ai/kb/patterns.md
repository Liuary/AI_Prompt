# 代码模式

> 项目约定、编码模式、最佳实践。

## [+] Skill 文件编写规范

所有 Skill 文件统一使用 Markdown 格式，文件名固定为 `SKILL.md`，放置在 `skills/{skill-name}/` 目录下。文件开头使用 YAML front matter 声明 name 和 description。执行步骤按数字序号组织，每个步骤含明确的操作指令和输出格式。Agent 调用 Skill 时按步骤顺序执行，禁止跳过或重排步骤。Skill 之间通过名称引用协作，检查索引文件或读取目标文件状态来判断前置条件是否满足。

## [+] 早返回模式减少嵌套

项目编码遵循早返回模式，函数体内先处理错误条件和边界情况并立即返回，避免深层嵌套。条件分支即使只有一行也必须使用大括号。异步操作统一使用 async/await，避免回调嵌套。变量声明优先使用 const（不可变），减少副作用。
