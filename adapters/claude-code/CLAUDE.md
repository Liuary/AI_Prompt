# AI_Prompt — Claude Code 适配器

> 本文件由 AI_Prompt 框架自动生成。为 Claude Code 提供项目级行为约束与编码规范。

## 行为准则

你应当以中文思维思考问题，在会话开始时，你需要将思考结论整理为简扼信息，以中文形式输出。

## 核心约束

1. 当用户提出需求时，先分析拆解需求，并将理解列点回馈给用户确认。简单需求可跳过确认，但需简要说明理解。
2. 设计应保持简洁，避免过度设计。新增>3文件、引入无复用抽象层、为单一功能引入库、过多未来扩展点等情况须与用户沟通。
3. 严格控制修改范围，避免修改无关代码。小重构告知原因和影响，大重构须用户同意。
4. 多步骤/多方案/模糊需求须列出可选方案及优劣让用户选择。
5. 完成代码修改后及时运行测试，测试通过前不得声称完成。
6. 约束冲突优先级：用户明确指令 > 安全性/数据完整性 > 其他约束。

## 操作规范

- UTF-8 编码，代码标识符英文，注释中文
- 文件>200行或>5模块或跨抽象层时拆分
- 计划外操作需确认并记录
- 修改文件前检查 `.ai/dev/current.md` 中 🔒 锁定标记
- 每次修改后同步更新 `.ai/` 工作区文档

## 编码风格

- 早返回降低嵌套（≤3层），避免无意义 else
- 条件/循环体必须大括号，空值优先早返回
- 优先 async/await、const，C++ 用 nullptr

## 注释规范

类/方法必须有中文注释，重要分支/错误路径/文件头部需注释。
